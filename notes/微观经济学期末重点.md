## 二、分模块重点梳理

### 1. 导论、供求理论与弹性分析

* **均衡分析（P9）**：局部均衡与一般均衡的区分；市场均衡价格与均衡数量的决定。
* **需求量的变化和需求的变化（P21）**：自身价格变化引起同一条需求曲线上点的移动（需求量的变化）；外生因素变化引起整条需求曲线的平移（需求的变化）。
* **需求的价格点弹性（P38）**：计算公式 $E_d = -\frac{dQ}{dP} \cdot \frac{P}{Q}$；点弹性与厂商销售总收入（$TR = P \cdot Q$）之间的关系。
* **需求的交叉价格弹性（P44）**：计算公式 $E_{XY} = \frac{dQ_X}{dP_Y} \cdot \frac{P_Y}{Q_X}$；若 $E_{XY} > 0$ 则为替代品，若 $E_{XY} < 0$ 则为互补品，若 $E_{XY} = 0$ 则为独立品。
* **价格管制（P48）**：最高限价（限制价格，低于均衡价格，导致超额需求与排队抢购）与最低限价（支持价格，高于均衡价格，导致超额供给与产品过剩）。

### 2. 消费者行为理论

* **边际效用递减规律（P62）**：一定时间内，在其他商品消费数量保持不变的条件下，随着消费者对某种商品消费量的增加，消费者从该商品连续增加的每一消费单位中所得到的效用增量即边际效用是递减的。
* **消费者偏好基本假定（P70）**：完备性、传递性、非饱和性（多多益善）、凸性。
* **无差异曲线（P72）**：带来相同效用水平的两种商品组合点的轨迹；特征包括斜率为负、不相交、密集性、凸向原点。
* **边际替代率与边际效用（P75）**：商品的边际替代率 $MRS_{XY} = -\frac{\Delta Y}{\Delta X} = -\frac{dY}{dX} = \frac{MU_X}{MU_Y}$；消费者均衡条件为 $MRS_{XY} = \frac{MU_X}{MU_Y} = \frac{P_X}{P_Y}$。
* **收入效应与替代效应（P90）**：总效应 $=$ 替代效应 $+$ 收入效应；正常品、低档品与吉芬品的替代效应、收入效应方向及需求曲线形状对比。

### 3. 生产者行为与成本理论

* **边际报酬递减规律（P141）**：短期生产中可变要素投入超过特定值后边际产量递减；短期生产三阶段划分与第 II 阶段合理投入区。
* **等产量线（P143）**：技术水平不变下生产同一产量的两种生产要素投入组合轨迹；边际技术替代率 $MRTS_{LK} = -\frac{dK}{dL} = \frac{MP_L}{MP_K}$，成本最小化（或产量最大化）均衡条件为 $\frac{MP_L}{w} = \frac{MP_K}{r}$。
* **规模报酬类型的判定（P158）**：对生产函数 $f(\lambda L, \lambda K)$（$\lambda > 1$），若 $f(\lambda L, \lambda K) > \lambda f(L, K)$ 则规模报酬递增，等于则规模报酬不变，小于则规模报酬递减。
* **成本的相关概念（P163）**：机会成本、显成本、隐成本、经济利润（超额利润）与正常利润。
* **短期成本函数（P168）**：$STC = TFC + TVC$，$SAC = AFC + AVC$，$SMC = \frac{d(STC)}{dQ}$；$SMC$ 曲线分别穿过 $AVC$ 曲线和 $SAC$ 曲线的最低点。
* **长期成本函数（P173）**：长期总成本 $LTC$、长期平均成本 $LAC$（短期平均成本曲线的包络线，呈 U 形取决于规模经济与规模不经济）与长期边际成本 $LMC$。

### 4. 完全竞争市场与不完全竞争市场

* **完全竞争市场（P189–P200）**：
    - 市场特征：无数买者与卖者、产品同质、资源自由流动、信息完全。
    - 需求与收益曲线：行业需求曲线向右下方倾斜，单个厂商面临水平需求曲线 $P = AR = MR$。
    - 短期均衡与短期供给曲线：$P = SMC$；停止营业点为 $P = AVC_{\min}$；厂商短期供给曲线是 $SMC$ 曲线上大于或等于 $AVC_{\min}$ 的部分。
    - 长期均衡：$P = MR = LMC = SMC = LAC = SAC$，经济利润为零（仅获正常利润）。
* **完全垄断市场（P215–P229）**：
    - 自然垄断（P215）：显著规模经济使一家厂商生产全部行业产量的平均成本低于多家厂商分别生产。
    - 垄断厂商需求曲线与短期均衡（P217, P220）：需求曲线即为市场需求曲线（向右下方倾斜），$MR < AR = P$，均衡条件为 $MR = SMC$。
    - 价格歧视（P222, P225）：一级（完全）价格歧视、二级价格歧视、三级价格歧视（条件：$MR_1 = MR_2 = MC$，需求弹性小的市场索取较高价格）。
    - 垄断的低效率（P229）：$P > MC$，产量低于竞争水平，价格高于竞争水平，存在无谓损失（社会福利净损失）。
* **垄断竞争与寡头市场（P235–P266）**：
    - 垄断竞争厂商的需求曲线（P235）：主观需求曲线 $d$（较平坦）与客观比例需求曲线 $D$（较陡峭）。
    - 古诺模型与古诺解（P243）：双寡头产量竞争反应函数与均衡产量（每个厂商均衡产量占市场总容量的 $\frac{1}{m+1}$）。
    - 斯威齐模型（P254）：弯折的需求曲线与间断的边际收益曲线，解释寡头市场价格刚性。
    - 四种市场类型经济效率的比较（P255）：完全竞争 $>$ 垄断竞争 $>$ 寡头垄断 $>$ 完全垄断。
    - 纳什均衡（P266）：给定对手策略时每个博弈方都选择了最优策略的策略组合。

### 5. 要素市场、福利经济学与市场失灵

* **厂商的要素使用原则（P279）**：使用要素的边际收益等于使用要素的边际成本（$\text{MRP} = \text{MFC}$）；完全竞争条件下为 $\text{VMP} = P \cdot MP_L = w$。
* **劳动供给曲线（P303）**：工资率上升的替代效应（增加劳动供给）与收入效应（增加闲暇、减少劳动供给）共同作用，高工资阶段收入效应超过替代效应导致个人劳动供给曲线向后弯曲。
* **阿罗不可能定理（P336）**：在非独裁的情况下，不可能存在一种社会福利函数能够同时满足所有个体偏好的完备性、传递性、帕累托原则和无关备选方案独立性。
* **外部性及其分类、影响与对策（P341–P345）**：生产的外部经济与外部不经济、消费的外部经济与外部不经济；外部不经济导致私人边际成本小于社会边际成本（$MC_P < MC_S$），私人均衡产量高于社会最优产量；对策包括征税与补贴（庇古税）、企业合并、明确产权与科斯定理。
* **公共物品与信息不对称（P352–P361）**：纯公共物品的非排他性与非竞争性，准公共物品；“搭便车”问题导致的公共物品供给不足；信息不对称引发的逆向选择、道德风险与委托-代理问题。
